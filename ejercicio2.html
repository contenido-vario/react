El Ahorcado

  1. Completa la lógica del juego para que funcione en JavaScript, cambiando el array de palabras a adivinar y llevandolo a un archivo .js aparte. Verás que en el mismo hay manipulación de .svg (2 puntos)
  2. Una vez completado, cambia los estilos de CSS nativo a Tailwind (1 punto)
  3. Reprograma el juego en React (2 puntos).
  4. Publícalo en GitHub bajo el nombre ahorcado-[tunombre].html Ejemplo: ahorcado-rita.html.
    Esta URL, será la entrega del mismo. (1 punto)
